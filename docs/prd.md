# 잠재력 발견 플랫폼 MVP PRD 요약

## 1. 제품 정의

20~30대 취업준비생이 자신의 흥미와 업무 역량을 짧게 진단하고, 현재 프로파일을 기준으로 탐색해 볼 직군 TOP 5와 관련 직업 정보를 얻는 웹 서비스입니다.

결과는 취업 성공확률, 능력 판정, 의료·심리 진단이 아닙니다. 한 사용자의 응답과 각 직군의 초기 요구 프로파일을 비교한 상대적 탐색 가이드입니다.

## 2. 사용자 문제

- 직군과 직무가 너무 많아 어디서부터 탐색해야 할지 어렵습니다.
- 성격검사 결과가 실제 직군 탐색과 잘 연결되지 않습니다.
- 흥미만으로는 전공·경력·지역·업무환경 같은 현실 조건을 함께 보기 어렵습니다.

## 3. MVP 목표

- 약 10분 안에 진단을 완료할 수 있습니다.
- 8개 직군 중 TOP 5를 보여 줍니다.
- 각 결과에 추천 이유, 확인할 점, 연관 직업 정보를 제공합니다.
- 같은 입력에는 항상 같은 결과가 나옵니다.
- API가 실패해도 미리 저장한 직업 정보로 결과 화면이 동작합니다.

## 4. 8개 직군

| ID | 직군 | 연관 직업 예시 |
| --- | --- | --- |
| J01 | 경영·사무·금융 | 경영기획, 인사, 회계·재무 |
| J02 | 연구·공학기술 | R&D, 기계·전기·화학 엔지니어 |
| J03 | IT·데이터 | 개발자, 데이터 분석가, QA |
| J04 | 교육·공공 | 교육기획, 직업상담, 행정·공공서비스 |
| J05 | 보건·의료 | 간호, 임상·보건, 의료기술 |
| J06 | 예술·디자인 | UX/UI 디자인, 콘텐츠 기획, 영상 편집 |
| J07 | 영업·마케팅 | B2B 영업, 브랜드·퍼포먼스 마케팅 |
| J08 | 서비스·운영 | 고객서비스, 매장·물류, 운영관리 |

이 분류는 KECO(고용24)를 참고해 제품 탐색용으로 정제한 것입니다. 공식 통계·자격 판정용 분류를 그대로 복제한 것은 아닙니다.

## 5. 사용자 흐름

```text
안내 및 한계 고지
→ 선택형 자기이해 입력
→ 12축 코어 진단
→ SJT 분기 문항
→ 현실 조건 입력
→ TOP 5 결과
→ 직군 상세·직업 정보 탐색
```

## 6. 점수 원칙

- 추천 점수: RIASEC 6축 + 핵심역량 6축, 총 12축만 사용합니다.
- 코어 문항은 5점 리커트 척도, 분기 문항은 SJT 상황 선택입니다.
- Big Five, MBTI, 에니어그램은 선택형 자기이해·결과 설명에만 씁니다.
- 학력·전공·경력·지역·연봉·업무환경은 직군 점수를 바꾸지 않고 상세정보의 필터와 확인할 점에 씁니다.
- LLM은 점수·순위를 바꾸지 못하며 계산된 근거를 설명하는 데만 사용합니다.

자세한 계산 방식은 [점수 모델](scoring-model.md)을 봅니다.

## 7. 비목표

- 취업 성공률 또는 합격 가능성 예측
- 한 가지 세부 직업의 자동 확정
- 멘토링, 퀘스트, 투자·후원, 커뮤니티
- 심리·의학 상담 또는 진단
- 실시간 전체 채용시장 분석

## 8. 팀 완료 기준

- 대표 사용자 3명이 진단부터 결과까지 완료할 수 있습니다.
- 8개 직군 모두 요구 프로파일과 연관 직업 정보를 갖습니다.
- 결과의 점수·순위·근거가 재현됩니다.
- 네트워크, LLM, API가 없어도 fallback 데이터로 발표할 수 있습니다.
