# 12축 직군 추천 점수 모델

## 1. 모델의 목적과 한계

이 모델은 사용자의 현재 응답을 기준으로 8개 직군의 탐색 우선순위를 정합니다. 취업 성공확률, 능력의 높고 낮음, 특정 직군을 할 수 있는지 여부를 판단하지 않습니다.

직군별 요구값과 가중치는 과학적 사실로 확정된 값이 아닙니다. 팀이 MVP를 위해 세운 초기 가설이며, 사용자 피드백과 검토를 통해 수정합니다.

## 2. 공통 12축

## 3. 문항과 사용자 벡터

각 12축에 리커트 문항 2개를 배정합니다. 사용자는 1점(전혀 아니다)부터 5점(매우 그렇다)까지 응답합니다.

```text
L(i) = 리커트 평균을 0~100으로 정규화한 값
S(i) = SJT 선택지에서 얻은 축별 행동 신호를 0~100으로 정규화한 값
U(i) = 0.70 × L(i) + 0.30 × S(i)
```

SJT 신호가 없는 축은 `U(i) = L(i)`로 계산합니다. 역문항을 쓴다면 정규화 전 값을 반대로 바꿉니다.

## 4. 직군 요구벡터와 적합도

각 직군은 12개 축의 요구값 `R(j,i)`과 축 중요도 `w(j,i)`를 가집니다.

- 요구값: 0~100
- 가중치: 0~1
- 한 직군 안의 가중치 합계: 1.00

```text
Fit(j) = 100 × [Σ(w(j,i) × U(i)/100 × R(j,i)/100)]
         ÷ [Σ(w(j,i) × R(j,i)/100)]
```

`j`는 직군, `i`는 12개 축입니다. 이 계산은 반드시 코드의 순수 함수로 구현하고, 같은 입력은 같은 결과를 반환해야 합니다.

## 5. 결과 밴드

점수는 한 사용자의 8개 직군 안에서만 비교합니다.

| 순위 | 결과 문구 |
| --- | --- |
| 1위 | 가장 높은 탐색 우선순위 |
| 2~3위 | 높은 탐색 우선순위 |
| 4~5위 | 함께 탐색 |

1위와 2위 점수 차가 3점 미만이면 `점수 차이가 작음`을 함께 보여 줍니다. 다른 사용자와의 백분위, 성공확률, 적성의 절대 등급은 보여 주지 않습니다.

## 6. 점수에 넣지 않는 정보

- MBTI, 애니어그램, 간단 Big Five: 선택형 자기이해와 설명 맥락에만 사용
- 학력, 전공, 경력, 희망 지역, 희망 연봉, 업무환경: 직업·채용 정보 필터 및 확인할 점에만 사용
- 성별, 나이, 출신지역, 장애, 가족상황 등 민감·보호 특성: 수집·점수화하지 않음

## 7. 구현 확인 목록

- [ ] 12축 모두 0~100 범위로 저장한다.
- [ ] 직군별 가중치 합계가 1.00인지 검증한다.
- [ ] SJT 선택지가 어떤 축에 어떤 점수를 주는지 데이터 파일에 명시한다.
- [ ] 동점은 `Fit 점수 → 직군 ID` 순으로 정렬한다.
- [ ] 점수·가중치·문항 버전을 결과와 함께 저장한다.
