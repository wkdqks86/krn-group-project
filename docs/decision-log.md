## 2026-08-18 · P2 결과·화면 문구 톤앤보이스 정합 (v0.1)

### 결정

- 사용자 대면 문구의 단일 출처로 `data/copy.json`(P2 소유)을 신설. 화면 microcopy·결과 근거/주의 템플릿·밴드 라벨·금지어 목록을 한곳에서 관리.
- `services/explainer.py`는 점수를 재계산하지 않고 `copy.json`의 템플릿에 `component_scores`/`cautions`의 축 라벨만 끼워 문장을 만든다(함수 시그니처 불변, LLM 분리 유지).
- `app.py`는 랜딩 첫 줄·시작 버튼·진행 격려·계산 대기 스피너·결과 상단/마무리 문구를 `copy.json`에서 읽도록 연결(로직 변경 없음, 문구만 교체).
- 결과 밴드는 엔진의 순위 기반 라벨(가장 높은/높은/함께 탐색)을 유지하되, 화면에는 완화된 표현으로 매핑("지금 가장 먼저 살펴볼 만해요" 등).

### 이유

- 기존 결과 문구가 "○○ 응답(72)이 프로파일(85)과 가깝습니다"처럼 기계적이었고, 시트의 톤앤보이스 규칙(응답 인용 후 응원, 결핍어·단정어·예측어 금지, 감탄사·이모지 금지)이 화면에 반영되지 않았음.
- 문구를 코드에서 분리(copy.json)해, P2가 엔진·화면 코드를 건드리지 않고 카피만 교체·리뷰할 수 있게 함.

### 검증

- `pytest -q` 6/6 통과(엔진·분기 회귀 영향 없음).
- 데이터 성향 응답자 시뮬레이션에서 TOP5 근거/주의 문구가 정상 출력되고, 결핍·단정·예측 금지어 0건(랜딩의 승인 문구 "정답을 찾아 주지는 못해요"는 의도된 예외).

### 남은 P2 항목(회의 확정)

- 직군별 12축 요구값·가중치 워크숍(D-13): 현재 `job_profiles.json` 값은 v0.1 가설. 회귀 테스트(J03 최상위 기대)와 얽혀 있어 조정 시 `tests/test_scoring.py`도 함께 검토.
- 문항 원문 다듬기(D-18).
- 밴드 표현 문구 최종 컨펌(카피 리뷰).
