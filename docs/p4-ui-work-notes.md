# [P4] UI 작업 설명 — `p4/result-cards`

작성 브랜치: `p4/result-cards`  
주요 변경 파일: `app.py`

## 요약

P4 Frontend/UX 관점에서 랜딩 → 선택 입력 → 진단 → 추가 정보 입력 → 결과/상세 화면의 시각·동선을 정리했다.  
추천 점수 로직은 바꾸지 않고, 안내·입력·진행 UI를 일관된 박스/칩 스타일로 맞췄다.

## 화면별 변경

### 1. 랜딩 (`landing`)
- 시작 전 확인 영역 정리 (안내 박스 + 동의 체크 + 진단 시작)
- 동의 체크박스: 가운데 정렬, 문구 한 줄 표시
- Streamlit `horizontal_alignment="center"`, `width="content"`, `wrap=False` 활용

### 2. 선택 입력 (`optional`)
- 안내 문구·MBTI·애니어그램을 박스(`border` / note box)로 통일

### 3. 진단 (`diagnose`)
- 제목/진행 UI: 응답 진행률, STEP·모듈·progress를 한 박스로 구성
- 중간 격려 문구(`절반 넘었어요. 편하게 답하면 돼요.`) 제거
- 보기 선택 후 **다음**으로 진행 (자동 제출 최소화)
- 모듈 순서 유지 + 모듈 내부 문항 셔플

### 4. 추가 정보 입력 (`context`)
- 제목: **현실 조건** → **추가 정보 입력**
- 안내 문구 박스 처리
- 최종 학력 / 경력 / 희망 근무지역 / 업무 방식 선호도를 선택 입력 화면과 같은 박스 형태로 정리

### 5. 결과·상세 (`result` / `detail`)
- 결과 섹션·성향 요약·연관 직업 카드 타이포/박스 정리
- 상세 화면 히어로·직업 카드 계층 정리

## 확인 체크리스트

- [ ] 랜딩에서 동의 체크 후 진단 시작
- [ ] 진단 진행률·이전/다음 동작
- [ ] 추가 정보 입력 후 결과 보기
- [ ] 결과 TOP 직군 → 연관 직업 상세
